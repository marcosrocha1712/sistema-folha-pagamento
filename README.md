# Sistema de Gerenciamento de Funcionários e Folha de Pagamento

## Descrição
Projeto acadêmico desenvolvido em Java para a disciplina de Programação Orientada a Objetos.

O objetivo é desenvolver um sistema para gerenciar funcionários e realizar cálculos relacionados à folha de pagamento.

## Funcionalidades implementadas
- Cadastro de funcionários.
- Listagem de funcionários cadastrados.
- Busca de funcionários por identificador.
- Remoção de funcionários.
- Cálculo de salário líquido com descontos.
- Cálculo do total da folha de pagamento.
- Exibição de relatório de salários.

## Tecnologias utilizadas
- Java
- IntelliJ IDEA
- Maven
- JUnit 5
- Git e GitHub

## Organização do projeto
- `src/main/java`: código principal do sistema.
- `src/test/java`: testes automatizados.
- `pom.xml`: configuração do Maven.

## Como executar
1. Abrir o projeto no IntelliJ IDEA.
2. Configurar o JDK e importar as dependências do Maven.
3. Executar os métodos de teste ou utilizar as classes do sistema em uma aplicação Java.

## Como executar os testes
No IntelliJ IDEA, clicar com o botão direito sobre o pacote de testes e selecionar **Run Tests**.

Também é possível executar os testes pelo Maven, quando estiver configurado:

`mvn test`

## Testes
O projeto utiliza JUnit 5 para testar funcionalidades de cadastro, consulta, remoção e cálculos de salários.
